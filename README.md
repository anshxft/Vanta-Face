# VantaFace

VantaFace is a premium personal improvement website with onboarding, routines,
progress tracking, photo analysis, and VantaScore.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

Import this repository into Vercel and keep the default settings.

- Install command: `npm install`
- Build command: `npm run build`
- Output directory: leave empty
